Task 1
Project Task: Legal Contract Document Modification System

Project Overview:
Develop a Legal Contract Document Modification System that allows users to upload, manage, review, modify, and track legal contract documents digitally.

The system should allow authorized users to modify contract details or clauses while maintaining the previous version, modified version, modification history, and approval status.

Main Objective

The main objective of this project is to create a secure system where legal documents can be:

Uploaded and stored
Viewed and managed
Modified by authorized users
Reviewed and approved
Version-controlled
Tracked through complete modification history
Example Workflow

Upload Contract → Review Contract → Modify Clause → Save New Version → Send for Approval → Approve/Reject → Maintain History

Technology

Java: Spring Boot, REST API, Spring Security, JPA/Hibernate, MySQL/PostgreSQL

Python: FastAPI, document processing/NLP libraries, MySQL/PostgreSQL

Expected Outcome

At the end of the project, the student should have a working application that demonstrates contract management, document modification, version control, approval workflow, and audit/history tracking.

task 11

Version Management and Audit Log
Implement Version Management so that a new contract version is created when a modification request is approved.
The system should maintain both the current version and previous versions of a contract.
Implement Version History so that users can view changes across different contract versions.
Also implement an Audit Log to record important system activities.
Each audit record should contain:
•	Action performed
•	User who performed the action
•	Date and time
•	Related contract or record
Create interfaces to display Version History and Audit Logs.
Expected Result: The system should maintain a complete history of contract changes and important user activities.
